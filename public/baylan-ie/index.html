Baylan IE — Kiosk PC Kurulumu

Bu sayfayı kiosk Windows bilgisayarında açın (sunucuda değil).

BAYLAN'a tıklanınca aşağıdaki adres Edge IE modunda, onay penceresi olmadan açılır.
Bunun için kurulumu bir kez kiosk PC'de çalıştırın.
1) Otomatik kurulum (.cmd) veya .reg indir
  1. kurulum.cmd indirip çift tıklayın → yönetici onayına Evet deyin.
  2. Edge, Baylan avans kredi sayfasını IE modunda test için açar; .cmd kendini siler.
  3. Chrome'u tamamen kapatıp yeniden açın.
  4. İsterseniz chrome://policy → AutoLaunchProtocolsFromOrigins kontrol edin.
  5. Kiosk'tan BAYLAN'a tıklayın → doğrudan Edge IE açılır (Aç/İptal yok).
